01 What the system does

One sentence: it takes a single grayscale MRI photograph of a head, finds the brain tumor in it, and draws the tumor's outline automatically.

An MRI slice is a single 2D cross-section image through a patient's head, the way one slice of bread is a cross-section of a loaf. This system works on T1-weighted contrast-enhanced slices, meaning the patient was given a contrast dye before scanning that makes many tumors light up brighter than the tissue around them. That brightness difference is the entire physical basis for everything this software does.

Segmentation means deciding, for every single pixel in the image, whether it is tumor or not tumor. The output is a mask: an image the same size as the input where each pixel is simply true (tumor) or false (not tumor). Compare that mask against a mask a human expert drew by hand — the ground truth — and you can score how well the software did.

The specific method used is Seeded Region Growing (SRG). You place a seed — one or a few starting pixels known to be inside the thing you want — and the algorithm repeatedly absorbs neighbouring pixels that look similar enough, spreading outward like ink soaking into paper until it reaches the object's edge.

The project has two halves that must be kept mentally separate:

HalfWhat it isWhy it exists
SRG The original 1994 published algorithm, implemented faithfully and left alone. The control. It is the yardstick the enhanced version must beat. Its value comes entirely from being unmodified.
ESRG The enhanced version: automatic seeding, a bias-resistant difference measure, and a stopping rule. The contribution. Three named objectives, each a specific fix for a specific documented failure of the original.

The three enhancements, which recur throughout this manual as "Objective 1/2/3":

  1. Objective 1 — automatic seeding. The original requires a human to click the seed. ESRG finds it by itself, or refuses and reports "no tumor candidate" rather than guessing.
  2. Objective 2 — a local log-domain difference measure. MRI scanners impose a smooth brightness gradient across the image (the bias field). This makes the same tissue look brighter on one side of the image than the other, which confuses a naive comparison. Working in the logarithm and comparing only against nearby absorbed pixels cancels it.
  3. Objective 3 — an adaptive stopping criterion. The original never stops until every pixel is consumed. ESRG computes a statistical boundary from the region's own variability and halts there, so the tumor region does not bleed into healthy brain.

03 Region growing, from top to core

Four descents, each one level simpler than the last, ending at the single line of arithmetic the whole system rests on.

Level 1 — the goal

Given an MRI slice, produce a mask marking the tumor. Score it against a human-drawn mask.

Level 2 — the strategy

Rather than classify each pixel independently (which ignores that tumors are contiguous blobs), start from a point known to be tumor and expand outward, only accepting pixels that resemble what has been accepted so far. This guarantees the output is one connected blob, which matches what a tumor physically is.

Level 3 — the mechanism

The loop, in five steps:

  1. Mark the seed pixels as belonging to the region. Compute the region's mean intensity μ.
  2. Look at every unclaimed pixel touching the region. For each, compute δ — how far its intensity is from μ.
  3. Put them all in the SSL, sorted by δ.
  4. Take the smallest δ. Absorb that pixel into the region. Update μ to include it. Add that pixel's newly-exposed neighbours to the SSL.
  5. Repeat from step 4.

The only difference between the original algorithm and the enhanced one is when this loop stops and what exactly δ measures. Everything else is shared.

Level 4 — the core arithmetic

Strip away all structure and one subtraction remains:

The difference measure, classical form

δ(x) = | I(x) − μregion |
I(x) = intensity of candidate pixel x
μregion = mean intensity of the region considering it
| · | = absolute value, so δ is never negative
→ δ is small when the pixel looks like the region already does.

That is it. Sorting by this number, absorbing the winner, and updating μ is Seeded Region Growing. The 1994 paper's contribution was the ordering — always taking the globally best-fitting pixel next, rather than sweeping outward blindly — because that ordering makes the result insensitive to which direction you happen to grow first.

04 The two algorithms

Both live in esrg/growing.py. They share the neighbourhood definition and the SSL, and differ in everything that decides membership.

The published baseline — grow_srg

Control group No stopping rule Whole image

esrg/growing.py:175. Signature: grow_srg(img, seed_labels). It receives the raw normalized intensity image and an integer seed map — an array where each planted seed pixel carries a number identifying which region it belongs to (1, 2, 3, …) and 0 means unseeded.

The five properties that make it faithful to the paper:

  1. Every region grows at once, under one identical rule. No region id is special-cased anywhere in the loop. Relabelling which number sits on the tumor produces pixel-for-pixel identical output.
  2. δ is the raw distance to the region mean, computed on plain intensities — no logarithm, no local window.
  3. δ is fixed when the pixel enters the SSL and never recomputed. The original has no re-scoring step; a pixel is absorbed into the region it was queued for.
  4. Absorption is unconditional. There is no threshold and no rejection. The winner of each round is always absorbed.
  5. It runs to complete tessellation. The loop ends only when the SSL is empty, which can only happen once every pixel in the image belongs to some region. It operates on the whole image, not a masked subregion, because the published algorithm has no skull-stripping step.
while ssl:
    _, r, c, lid = heapq.heappop(ssl)
    if label[r, c] != 0:
        continue                    # a better-fitting region reached it first
    label[r, c] = lid               # unconditional: no stopping rule, no re-scoring
    sums[lid] += float(img[r, c])
    counts[lid] += 1
    for dr, dc in NEIGH8:
        enqueue(r + dr, c + dc, lid)
esrg/growing.py — the entire absorption loop. Nine lines.

It returns the full label map, not a tumor mask. Which region is "the tumor" is not decided inside the algorithm — the caller reads out whichever id the user planted on the tumor. This matters: SRG has no concept of a privileged region, and the code reflects that.

Consequence of having no stopping rule

If you plant only one seed type, that region has nothing to compete against and absorbs the entire image — correctly, per the algorithm. The code detects this and raises a warning rather than silently returning a full-image mask. You must seed every distinct tissue you don't want merged, including the dark background outside the head.

The enhanced version — grow_esrg

Objective 2 Objective 3 Head mask only

esrg/growing.py:65. Signature: grow_esrg(L, mask, core, sigma_floor, cfg), where L is the log-domain image. Four structural differences from the baseline:

1. δ is local and logarithmic (Objective 2)

Instead of comparing to the whole region's mean, it compares to the mean of absorbed pixels within a small window around the candidate — a (2r+1)×(2r+1) box, 7×7 by default. The class _LocalMean maintains this. If no absorbed pixel is nearby yet, it falls back to the global region mean.

2. Growth runs in passes, with statistics frozen

Rather than one continuous loop, growth proceeds in up to max_passes (default 4) sweeps. At the start of each pass, μ and σ are read once and held constant for the whole pass. This is deliberate:

Why freezing matters

If σ updated after every pixel, each marginally-accepted pixel would widen σ slightly, which loosens the threshold, which admits the next marginal pixel, which widens σ again. That positive feedback is exactly how leakage happens. Freezing per pass breaks the loop.

3. Two thresholds gate every absorption (Objective 3)

A local bound T_L stops the pass entirely when the best remaining candidate fails it — valid because the SSL is sorted, so if the best fails, all the rest fail too. A global drift guard T_G rejects individual pixels that have wandered too far from the original region mean, which blocks slow chaining across a soft boundary.

4. It keeps lazy re-evaluation

Because the local mean genuinely moves as neighbours get absorbed, ESRG rechecks δ when a pixel is popped and re-queues it if it has grown stale (tolerance lazy_tol). This is an intentional enhancement, and is precisely the behaviour that was removed from the baseline to keep the baseline faithful.

05 The pipeline, stage by stage

esrg/pipeline.py runs these in fixed order and keeps every intermediate result, so a bad final mask can always be traced back to the stage that caused it. Each stage becomes a clickable button in the app.

A Stage (esrg/pipeline.py:26) records: a short key, a display name, the image to show, how to draw it, a dictionary of diagnostics, elapsed seconds, and a status of OK / WARN / FAIL. A Result holds the list of stages plus the final mask, the ground truth, the scores, and metadata.

Note this isolates the head, not the brain: on 2D slices the face and neck connect to the brain through the skull base, so no erosion cleanly separates them. Telling interior tissue from scalp is deferred to seed selection, which uses the depth map.

Needs

Log domain

Compute L = ln(img + eps) and estimate the image's noise floor — a robust lower bound on σ, so that a perfectly uniform seed can't produce a σ of zero and a threshold of zero.

In

Out
L, sigma_floor
Used by

4

Candidates

Multi-Otsu splits interior tissue into K brightness classes; the brightest class becomes the candidate pool. Blobs are then filtered by area and by clearance — how far a blob's deep centre sits inside the head beyond its own radius. Scalp fat is the brightest tissue on T1 and forms a ring hugging the outline; clearance near zero identifies and rejects it, while a real tumor sits well inside.

In
Masked image, head mask, depth map
Out
Candidate blobs with measurements
5

Seed core

Surviving candidates are ranked (contrast, interiority, shape) and the winner's deepest interior pixels become the seed core — specifically pixels at least seed_core_frac of the way to the blob's deepest point, keeping the seed away from blurry partial-volume edge pixels. In manual mode this stage instead builds the seed map from your clicks.

Out
core (boolean) and seed_labels (integer map)
Status
FAIL and a hard stop if nothing survives — the system reports "NO TUMOR CANDIDATE" rather than seeding arbitrarily
6

Region growing

Dispatches to grow_srg or grow_esrg depending on the method setting. For SRG an extra stage 6a · Full tessellation is inserted, showing every grown region in its own colour so you can confirm that all regions grew and that no pixel was left unallocated.

Out
Boolean region mask + a trace of what happened
7

Final

Cleanup, then scoring. Interior holes are filled (ring-enhancing tumors have dark necrotic centres that belong inside the mask), a light opening shaves thin protrusions, and only the connected component containing the seed is kept. If the result covers more than leak_warn_frac of the head, the stage is flagged WARN for probable leakage.

Out
result.mask, plus all scores if ground truth was found

06 Equations, with real numbers

Every formula the system uses, where it lives, and a worked substitution showing what it does to the output. Numbers below are computed from a realistic bright-tumor seed.

6.1 Normalization

preprocessing.normalize

I′ = clip( (I − p0.5) / (p99.5 − p0.5), 0, 1 ) × 255
p0.5, p99.5 = the 0.5th and 99.5th percentile intensities
Why percentiles, not min/max: a single blown-out hot pixel would otherwise compress the entire image into a narrow band.
→ with p0.5=12, p99.5=228, a raw pixel of 120 becomes (120−12)/216 × 255 = 127.5

6.2 The log transform — why it defeats the bias field

preprocessing.log_transform  ·  L(x) for every pixel

L(x) = ln( I(x) + ε )    ε = 1.0
ε prevents ln(0), which is undefined. 1.0 is negligible against a 0–255 range.
The bias field multiplies: observed = true × b, where b varies smoothly across the image.
In logs that becomes ln(true × b) = ln(true) + ln(b) — a constant added offset.

Substituting real values proves it. Take two very different tissues, both under a 1.2× bias:

TissueTrue ILBiased I (×1.2)LShift in L
Bright tumor2005.30332405.4848+0.1815
Mid grey matter1004.61511204.7958+0.1807
Read the last column

In raw intensity the bias shifted the bright pixel by +40 and the dark pixel by +20 — completely different distortions. In the log domain both shifted by ≈ +0.181 (which is ln 1.2 = 0.1823). The distortion became one shared constant. And because ESRG's δ compares a pixel against its local neighbours, who carry the same constant, it cancels in the subtraction entirely. That is Objective 2 in two numbers.

6.3 Welford's online variance

growing._Welford — updates μ and σ one pixel at a time without re-reading the region

d = x − μ  ;  μ ← μ + d/n  ;  M₂ ← M₂ + d·(x − μnew)  ;  σ = √( M₂ / (n−1) )
n = count so far, M₂ = running sum of squared deviations.
Why not just recompute? Re-averaging thousands of pixels after every absorption would dominate runtime. Welford is exact and O(1) per update.
→ for L values 5.3033, 5.3279, 5.2781 (intensities 200, 205, 195): μ = 5.3031, M₂ = 0.001239, σ = √(0.001239/2) = 0.0249

6.4 The noise floor

preprocessing.noise_floor — a σ that can't collapse to zero

σfloor = max( 1.4826 × MAD( L − median3×3(L) ), 0.02 )
MAD = median absolute deviation = median( |v − median(v)| ).
The 1.4826: for normally-distributed data, σ ≈ 1.4826 × MAD. It converts a robust spread measure into a standard-deviation equivalent.
Why subtract a median filter first: that removes real anatomy and leaves only pixel-to-pixel noise, which is what we want to measure.
→ guards against a perfectly uniform seed giving σ = 0, which would make every threshold zero and freeze growth instantly.

6.5 The ESRG difference measure and its two bounds

growing.grow_esrg — Objectives 2 and 3 together

δ(x) = | L(x) − mlocal(x) |
TL = kL · σA     TG = kG · σA     σA = max(σregion, σfloor)
mlocal(x) = mean L of absorbed pixels in the (2r+1)×(2r+1) window around x
Absorb x only if δ(x) ≤ TL and |L(x) − μA| ≤ TG
δ > TL ends the pass (the SSL is sorted — if the best fails, all fail)
Failing only TG rejects that pixel alone and continues

With the seed above (σA = 0.0249) and defaults kL = 1.5, kG = 3.0: TL = 0.0373, TG = 0.0747. Testing candidates against a local mean of 5.3031:

6.6 The SRG difference measure

growing.grow_srg — plain intensities, best-fitting neighbour wins

δ(x, R) = | I(x) − μR |    where μR = sums[R] / counts[R]
Each candidate is queued once per region that reaches it; the SSL pops the global minimum.
→ tumor region μ = 200, background region μ = 40:
  candidate I = 198 → δtumor = 2, δbg = 158 → tumor wins
  candidate I = 44  → δtumor = 156, δbg = 4 → background wins
After absorbing 198: sums 200→398, counts 1→2, μtumor = 199.0

6.7 Candidate ranking

seed_ranking.score_candidates

score = wc·ĉ + wr·r̂ + ws·½(compactness + solidity)
ĉ, r̂ = contrast and inscribed radius, each rescaled to 0–1 across the candidates
contrast = mean(blob) − mean(ring just outside it)
compactness = 4π·area / perimeter²  (exactly 1.0 for a perfect disk)
solidity = area / area of its convex hull  (1.0 = no concavities)
defaults wc = 0.5, wr = 1.0, ws = 0.2

Two candidates, to show the weights deciding an outcome:

Blobradiuscontrastr̂ĉshapescore
A — small, very bright121150.01.00.900.680
B — larger, dull14201.00.00.631.125

B wins because interiority carries twice the weight of contrast. Raise rank_w_contrast to 2.0 and A scores 2.18 against B's 1.125 — the ranking flips. This single knob decides which blob gets seeded on ambiguous slices.

6.8 Clearance — how scalp is told apart from tumor

seeds.select_seed

clearance = depth(centre) − radius
depth(centre) = distance from the blob's deepest pixel to the head outline
radius = that blob's own inscribed radius
→ tumor: depth 25, radius 12 → clearance 13 ≥ 8 → kept
→ scalp strip: depth 6, radius 5 → clearance 1 < 8 → rejected
A blob riding the outline has its deepest point at roughly its own radius, so clearance ≈ 0.

6.9 The accuracy scores

metrics.evaluate — TP / FP / FN are pixel counts against ground truth

DSC = 2·TP / (2·TP + FP + FN)     IoU = TP / (TP + FP + FN)
Precision = TP / (TP + FP)     Recall = TP / (TP + FN)
TP = predicted tumor that really is tumor  ·  FP = predicted tumor that isn't  ·  FN = real tumor that was missed
→ TP = 1500, FP = 200, FN = 300:
  DSC = 3000/3500 = 0.857   IoU = 1500/2000 = 0.750
  Precision = 1500/1700 = 0.882   Recall = 1500/1800 = 0.833

DSC (Dice Similarity Coefficient) is the headline number in this field: 0 is no overlap, 1 is perfect. It weights agreement double, which makes it more forgiving than IoU for the same masks — the two always relate as DSC = 2·IoU / (1 + IoU). Precision falling while recall stays high is the signature of leakage; the reverse means the region stopped too early.

metrics.surface_distances — boundary accuracy, not area accuracy

HD95 = 95th percentile of all boundary-to-boundary distances    ASSD = their mean
Distances are measured both ways (predicted edge → true edge, and true edge → predicted edge), then pooled.
Why the 95th percentile rather than the maximum: one stray pixel would otherwise dominate the entire score.
Units are pixels at the working resolution, not millimetres — see §11 for why that matters.

09 Parameters and what they do

The four on-screen parameters in depth, then the full config table for everything not exposed in the interface.

kL — the local stopping factor ESRG only

Default 1.5. Multiplies σ to produce the acceptance threshold. This is the single most consequential dial in the system: it directly trades completeness against leakage.

  • Lower it when the mask floods into healthy brain. The region becomes conservative and stops at the first hint of an edge.
  • Raise it when the mask captures only the tumor's brightest core and misses its dimmer rim.
  • Above roughly 2.5, infiltrative tumors (gliomas especially) tend to leak, because their boundary genuinely is within that statistical band — no threshold can separate what is not separable by intensity alone.
  • Remember it also drags k_G upward past 2.0.

r — neighbourhood radius ESRG only

Default 3, giving a 7×7 window. Controls how local Objective 2's comparison is.

  • Smaller (1–2) tracks the bias field very closely, but the mean rests on few pixels and becomes noisy — the measure starts chasing individual pixel noise.
  • Larger (6–8) gives a stable mean but begins to average across the bias gradient itself, gradually surrendering the advantage over a global mean.
  • Cost is negligible: the window is summed from an array, so runtime barely moves.

K — Otsu classes affects seeding

Default 3. How many brightness groups interior tissue is divided into; the top group becomes the candidate pool.

  • K = 2 is plain Otsu — one cut, a broad bright class that often swallows normal enhancing structures alongside the tumor.
  • K = 3 separates dark / mid / bright, which matches T1-CE anatomy well.
  • K = 4–5 makes the top class very selective. This can help on a brilliantly enhancing tumor and can equally cause total failure — if the tumor lands in the second class it never becomes a candidate and the run reports NO TUMOR CANDIDATE.

Overlay opacity display only

Has no effect on results whatsoever. Note it is used during export, so it changes what saved overlay PNGs look like.

10 Ablation & research switches

An ablation is an experiment that removes one component to measure what it was contributing. If performance drops when you disable a feature, that drop is the feature's measured value — this is how the thesis proves each objective earns its place rather than merely asserting it.

The two objective switches

use_log_local and use_stopping are the scientific heart of the evaluation. Together they define four combinations, which experiments/ablation.py runs as five arms alongside the SRG baseline:

Armuse_log_localuse_stoppingWhat it isolates
SRG baseline——The 1994 floor. Everything must be measured against this.
Global δ, no stopoffoffRegion growing with neither enhancement — the weakest ESRG-shaped arm.
Global δ + stopoffonThe value of Objective 3 alone.
Local log δ, no stoponoffThe value of Objective 2 alone.
ESRG (full)ononBoth together — reveals whether they interact or merely add.

Turning off use_stopping

The threshold checks are skipped entirely and absorption becomes unconditional. Growth is then bounded only by the head mask and max_passes. Expect recall to rise toward 1.0 while precision collapses — the region swallows the brain. This is the clearest demonstration of why Objective 3 exists.

Turning off use_log_local

δ reverts to abs(L[r,c] - stats.mean) — still logarithmic, but anchored to the whole region. The failure it reintroduces is specific and worth understanding: where the bias field has brightened one side of the tumor, that side's pixels now sit far from the global mean and are rejected, so the mask becomes lopsided — truncated on the bright side, or leaking on the dim side. It is a subtler degradation than the stopping ablation, and it is exactly the degradation the numbers in §6.2 predict.

use_n4

Inserts a full N4ITK bias-field correction before the log transform. Its purpose in the study is a fairness argument: if ESRG with its cheap log-domain trick performs comparably to ESRG with heavyweight explicit correction, then Objective 2 is doing real work at a fraction of the cost. Requires SimpleITK; the stage fails gracefully with a FAIL badge if unavailable.

The Phase 1 / 2a / 3 research switches

These were implemented, evaluated on the full test set, and found not to beat the tuned baseline. They ship disabled but intact. That is a deliberate and honest choice: a negative result that is reproducible is a finding, and keeping the code switchable lets a reader verify it rather than take it on trust.

SwitchDefaultIntent · measured outcome
rank_use_contraston Rank candidates by brightness against their surround. Kept on at weight 0.5 — useful, but secondary to interiority at 1.0.
rank_use_shapeon Mild compactness and solidity tie-break at weight 0.2. Kept deliberately mild because gliomas are genuinely irregular and a strong shape prior would penalise real tumors.
rank_use_vesselnessoff Frangi filter to veto tubular candidates (vessels). No aggregate gain on 2D slices and roughly 2× slower — vessels rarely survive the area and clearance filters anyway.
exclude_orbitsoff Forbid bright round structures in the upper head (eyeballs). No aggregate gain: orbits are dark on most T1 slices and Otsu already drops them.
exclude_skull_baseoff Forbid a thin band of bright skull-base marrow. Helped a small minority of slices, not enough to justify the risk of clipping genuinely low-sitting tumors.
adaptive_koff Set k_L per image from the seed's contrast against its surrounding ring — loose for high-contrast tumors, tight for low-contrast ones. Sound reasoning, but it did not beat a well-chosen fixed k_L on meningioma.
How adaptive_k works if you enable it

It measures contrast between the seed's mean and a ring around it, maps that onto 0–1 against adaptive_ref_contrast, and interpolates k_L between adaptive_k_lo (1.3) and adaptive_k_hi (2.0). The chosen value is reported in the growth stage telemetry as adaptive_k_local, so you can always see what it picked. k_G stays fixed.

11 Ground truth and its accuracy

The green outline is not produced by the algorithm. It is a separate human-drawn image the system locates, loads, and draws on top — the reference the prediction is judged against.

Step 1 — finding the file

find_mask_for in esrg/io_utils.py takes the image path, strips the extension to get the stem, and tries three locations in order: 

<parent>/masks/<stem>.png     ← the BRISC dataset layout
<folder>/<stem>.png           ← mask beside the image
<folder>/<stem>_mask.png      ← common alternative naming

The first existing file wins, with a guard preventing it from matching the input image itself. If none exist, result.gt stays None, no scores are computed, and the metrics bar says so rather than reporting zeros.

Step 2 — loading it as a boolean mask

io_utils.load_mask

gt = ( resizeNEAREST( grayscale(file) ) > 127 )
Converted to grayscale, resized to match the working image, thresholded at the midpoint of 0–255.
Nearest-neighbour resizing is required — any smoothing interpolation would invent intermediate grey values along the boundary and blur a crisp mask.

Step 3 — drawing the outline

visualize.outline — a one-pixel inner border

outline(m) = m AND NOT erode(m)
Erosion shrinks the mask by one pixel; subtracting it from the original leaves exactly the rim.
→ painted in green (34, 197, 94), at full strength rather than blended, so it stays legible at any opacity setting.

In the default final view the prediction is filled red with a red outline, and the ground truth is drawn as a green contour on top. With Show Error Heatmap enabled, the view switches to a direct comparison: green where both agree, red where the prediction is wrong, orange where real tumor was missed.

How accurate is the ground truth itself?

Four honest caveats, in decreasing order of practical impact:

1 · It is a human annotation, not physical truth

"Ground truth" is the field's term for the reference standard: one or more experts' hand-drawn opinion. Two radiologists tracing the same glioma routinely disagree at the infiltrative edge. A DSC of 0.85 against such a mask may be within the range that two humans would differ from each other — which is why DSC around 0.85 is treated as strong performance rather than a mediocre 85%.

2 · Metrics are measured in pixels, not millimetres

Because max_side downscales large inputs, HD95 and ASSD are expressed in pixels at the working resolution. Two images downscaled by different factors produce distance numbers that are not directly comparable, and none of them convert to physical millimetres without the scan's pixel spacing, which these JPEG inputs do not carry. Overlap metrics (DSC, IoU, precision, recall) are ratios and are unaffected.

3 · Resizing can shift the boundary by about a pixel

When the image is downscaled, the mask is resized by nearest-neighbour to match. That is the correct choice, but it can move the boundary by up to one pixel in either direction. On a small tumor of, say, 300 pixels, a one-pixel rim is a meaningful share of the area.

4 · The threshold assumes near-binary masks

BRISC masks are effectively binary with a thin anti-aliased fringe, so > 127 is stable. A mask saved as a lossy JPEG, or one using a different label value convention, would need this reconsidered.

One further check, separate from the overlap scores: seed_hit reports whether the entire seed core landed inside the ground truth. This isolates Objective 1's performance from the growing stage — a run can have a perfect seed and a poor mask (growing failed) or a missed seed and a meaningless mask (seeding failed), and the two failures call for entirely different fixes.

12 The Stage Telemetry panel

The right-hand panel. Its purpose is to make the pipeline auditable: when the mask is wrong, this panel tells you which stage went wrong and why, so you tune the right parameter instead of guessing.

Built by _show_diagnostics at gui/app.py:478. It rebuilds whenever you select a stage button and prints, in order:

  1. A header — stage name, status (OK / WARN / FAIL), and duration in milliseconds.
  2. Every key in that stage's info dictionary, one per line.
  3. Any value that is a list of dictionaries gets a bulleted sub-block — this is how the per-pass growth trace is rendered.
  4. On the Final stage only, a SEGMENTATION ACCURACY section with every score.

The renderer is fully generic: it simply iterates whatever the stage put in info. Adding a diagnostic anywhere in the pipeline makes it appear here with no GUI change.

Timing

Every stage is wrapped by a timer in pipeline.run, so the duration is that stage alone. Region growing normally dominates; if a different stage is unexpectedly slow, that is itself a diagnostic.

Reading the growth trace

For ESRG, the passes block is the most informative output in the entire application. Each pass reports:

FieldMeaningWhat it tells you
muFrozen region mean (log units)Drifting upward across passes means the region is moving into brighter tissue.
sigmaFrozen region σGrowing rapidly means the region is absorbing varied tissue — the early warning of leakage.
T_LLocal bound for the passEquals k_L × sigma. Watch it widen pass to pass.
T_GGlobal drift boundEquals k_G × sigma.
addedPixels absorbed this passA late pass adding thousands is leakage in progress.
areaTotal region size after the passShould plateau. Continued climbing is the problem signature.
stopWhy the pass endedEither queue exhausted or the exact δ and threshold that halted it, e.g. delta 0.184 > T_L 0.056.

A healthy run looks like a large first pass, progressively smaller additions, and then a pass adding zero — reported as converged after pass N. Hitting reached P_max means growth was still going when it ran out of passes, so the result is truncated rather than converged.

SRG telemetry

The baseline has no passes. It reports stop reason (always tessellation complete), seed regions, and unlabeled px — which should always read 0, since that is the defining property of the algorithm. The separate 6a · Full tessellation stage lists region areas and region means for every planted region; those areas summing to the total pixel count is the direct proof that every pixel was allocated.

13 Glossary of every symbol

Every symbol, variable and term used above, in one place.

I(x)
Intensity of pixel x, on the normalized 0–255 scale.
L(x)
Log-domain value of pixel x: ln(I(x) + ε).
ε (log_eps)
Small constant inside the logarithm preventing ln(0). Default 1.0.
δ (delta)
The difference measure — how poorly a candidate pixel fits a region. Small is good.
μ (mu), μA
Mean of the region. In ESRG, frozen at the start of each pass.
σ (sigma), σA
Standard deviation of the region, clamped below by the noise floor.
σfloor
Robust noise estimate from the image, preventing σ from reaching zero.
M₂
Welford's running sum of squared deviations; σ = √(M₂/(n−1)).
MAD
Median Absolute Deviation — a robust spread measure, converted to σ-equivalent by ×1.4826.
mlocal
Mean of absorbed pixels inside the local window around a candidate. The core of Objective 2.
r (local_radius)
Half-width of that window; the window is (2r+1)×(2r+1).
kL (k_local)
Multiplier producing the local acceptance bound.
kG (k_global)
Multiplier producing the global drift bound. Must exceed kL.
TL
Local bound, kL·σA. Exceeding it ends the pass.
TG
Global drift bound, kG·σA. Exceeding it rejects that pixel only.
Pmax (max_passes)
Maximum number of growth sweeps in ESRG. Default 4.
K (otsu_classes)
Number of brightness classes multi-Otsu splits tissue into.
α (seed_core_frac)
Fraction of maximum blob depth a pixel must reach to join the seed core.
SSL
Sequential Sorted List — the δ-ordered queue of candidates.
NEIGH8
The eight neighbour offsets, diagonals included. Used by both growers.
Seed map / label map
Integer array where each value identifies which region a pixel belongs to; 0 means unassigned.
Tessellation
A complete partition — every pixel assigned to exactly one region, none left over.
Depth map
Distance of each pixel from the head outline, from the distance transform.
Clearance
depth(centre) − radius. Near zero for scalp, large for interior tumors.
Compactness
4π·area / perimeter². 1.0 for a perfect disk.
Solidity
Area divided by convex-hull area. 1.0 means no concavities.
Vesselness
Frangi filter response, high on tubular structures like vessels.
TP / FP / FN
True positive, false positive, false negative — pixel counts against ground truth.
DSC
Dice Similarity Coefficient, 2TP/(2TP+FP+FN). The headline accuracy score.
IoU
Intersection over Union, TP/(TP+FP+FN). Always ≤ DSC.
HD95
95th percentile of symmetric boundary distances, in pixels.
ASSD
Average Symmetric Surface Distance — mean of those same distances.
Leakage
The region escaping through a weak boundary into healthy tissue.
Bias field
The scanner's smooth multiplicative brightness distortion.
N4 / N4ITK
Standard algorithm that estimates and removes the bias field explicitly. Ablation arm only.
Ablation
Disabling one component to measure its contribution.
Ground truth
The expert-drawn reference mask used for scoring.
seed_hit
True when the entire seed core lies inside the ground truth — isolates Objective 1's success from growing.
