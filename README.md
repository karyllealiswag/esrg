# ESRG — Enhanced Seeded Region Growing for MRI Brain Tumor Segmentation

An enhancement of the Adams & Bischof (1994) Seeded Region Growing (SRG) algorithm for
localization and delineation of brain tumors on 2D contrast-enhanced T1-weighted MRI slices.

Three enhancements over the classical algorithm:
1. Automatic, deterministic seed selection (Objective 1).
2. A local difference measure computed in the log domain, insensitive to the MRI bias field (Objective 2).
3. An adaptive stopping criterion that halts growth at weak boundaries (Objective 3).

## Install and run

```bash
pip install -r requirements.txt
python -m gui.app                       # desktop app (per-stage inspection)
python tests/test_pipeline.py           # unit tests (or: pytest tests/)
```

## Reproducing the study (BraTS 2023, glioma + meningioma)

The protocol, deviations and decisions are recorded in `experiments/PROTOCOL_BRATS.md` and
`experiments/IMPROVEMENT_PROTOCOL_ESRG*.md`. Run Python on data folders with `-P`.

```bash
python -P experiments/sampling.py --brats --draw       # patient-level 70/30 split -> brats_eval/
python -P experiments/sampling.py --brats --verify     # dataset checks
python -P experiments/tune.py --stage all              # tuning on the development set only
python -P experiments/improve_v3.py --stage rounds      # development-set improvement rounds (resumable; then --stage mirrors, --stage final)
python -P experiments/evaluate.py --set test --sample-per-type 300 --approved --analyze
python -P experiments/evaluate.py --set test --sample-per-type 300 --approved --repeat 1   # determinism
```

Chapters are built from the results, so every number is read from the output files:

```bash
python -P experiments/chapter3/build_chapter3.py                 # Chapter3_Methodology.docx
python -P experiments/chapter4/build_chapter4_brats.py           # Chapter4_Results_and_Discussion.docx
python -P experiments/chapter5/build_chapter5.py                 # Chapter5_Conclusions_and_Recommendations.docx
```

Result tables (`*.csv`) are kept locally and are not committed (see `.gitignore`); they are
regenerated by the scripts above. The test set is evaluated once, with the frozen
configuration `configs/esrg_brats_frozen_v3.json`.

## Layout

```
esrg/
  config.py           All parameters (Config dataclass, JSON save/load).
  io_utils.py         Image/mask loading, BraTS filename parsing.
  preprocessing.py    Normalize, brain mask, log transform, noise floor.
  seeds.py            Objective 1 — automatic seed selection, hard-fail on no candidate.
  seed_ranking.py     Contrast/shape candidate ranking.
  anatomy_exclusion.py Orbit/skull-base exclusion (research option, off by default).
  growing.py          Objectives 2 & 3 — grow_esrg; grow_srg baseline.
  postprocess.py      Hole fill, opening, seed-connected component.
  metrics.py          DSC, precision, recall, HD95, ASSD, seed hit.
  explain.py          Traceable per-slice computation of every metric (GUI Evaluation step).
  stage_report.py     Stage-by-stage computation report (GUI details panel).
  visualize.py        Stage rendering and annotated overlays.
  pipeline.py         Stage orchestration; retains every intermediate.
gui/app.py            CustomTkinter desktop app: stage tabs over Original | Output panes,
                      details panel, one-line metrics footer.
experiments/          sampling, tune, improve_*, evaluate, analyze_brats, stats, attribution;
                      chapter3/, chapter4/, chapter5/ (docx builders, shared render_docx.js).
configs/              Frozen parameter files (v1, v2, v3 = final).
tests/                Correctness and smoke tests.
```

## Results in brief

On the 600-patient BraTS 2023 test sample (300 glioma, 300 meningioma), the original SRG
with three planted seeds reached a mean DSC of 0.622 (glioma) and 0.850 (meningioma); the
ESRG with a planted tumor seed reached 0.554 and 0.806. The ESRG leaks less (higher
precision) but recovers less of the tumor (lower recall). Given the same single tumor click,
the original SRG absorbs the whole image, while the ESRG stops at the tumor. The automatic
seed lay inside the tumor on 85.0% of meningioma and 58.3% of glioma slices, and automatic
runs are bit-for-bit reproducible. Details and statistics are in Chapter 4.
